## 5. 文档阅读顺序（给开发者/答辩）

1. `README.md` → 快速跑起来
2. `docs/...-PRD.md` → 做什么（需求与边界）
3. `docs/...-ia-2026-11-17.md` → 页面与流程（23 页、J1–J5）
4. `docs/...-数据库设计说明书...md` + `db/schema.sql` → 数据模型
5. `docs/...-API接口契约...md` → 接口与错误码
6. `docs/...-权限矩阵...md` → 谁能做什么
