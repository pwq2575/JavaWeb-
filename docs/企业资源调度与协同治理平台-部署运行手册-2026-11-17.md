### 2.1 JDK 24 与 Java 17 的差异
- `maven.compiler.release=17` 约束的是**字节码与可用 API**：用 JDK 24 编译同样产出 17 兼容字节码，不必降级 JDK；差异在**运行期**——`java -jar` 用哪个 `java.exe` 就以哪个版本跑，演示与生产必须固定同一个。若某插件不认 JDK 24（报 `Unsupported class file major version 68`），再单装 JDK 17 并把 `JAVA_HOME` 指过去，而不是改 `release`。

## 3. 首次初始化
顺序固定：**检查服务 → 建库建账号 → 导入 `db/schema.sql` → 导入 `db/data.sql` → 验证**。Flyway **本期不启用**，全部走一次性 SQL 脚本（PRD §7.4），故 `pom.xml` 不引入 Flyway 依赖。

### 3.1 检查服务与建库建账号
```powershell
$mysql = 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe'
Get-Service MySQL80 | Select-Object Name, Status, StartType   # 期望 Running + Automatic
& $mysql -u root -p                                            # 本机 root 已设密码，交互输入
```
服务未运行时，在**管理员** PowerShell 执行 `Start-Service MySQL80`。进入 CLI 后执行：
```sql
CREATE DATABASE IF NOT EXISTS ers DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_0900_ai_ci;
CREATE USER IF NOT EXISTS 'ers_app'@'localhost' IDENTIFIED BY '<APP_DB_PASSWORD>';
GRANT SELECT, INSERT, UPDATE, DELETE ON ers.* TO 'ers_app'@'localhost';
FLUSH PRIVILEGES;
```
应用账号只授 DML，**DDL 一律由 root 执行**（建表、删库都在本手册的人工步骤里）。`<APP_DB_PASSWORD>` 现场设定，只写进本机环境变量。

### 3.2 导入建表与种子数据
两步顺序不可颠倒（`data.sql` 依赖表结构）。
```powershell
$repo = 'D:\企业资源调度与协同治理平台'
# 切到 db 目录，用 mysql 自带 source + 相对文件名：中文绝对路径不会被 mysql 客户端解析，最稳
# 已实测通过：重灌后 SHOW TABLES=12，sys_user=5 / asset=16 / reservation=6
Push-Location "$repo\db"
& $mysql -u root -p --default-character-set=utf8mb4 ers -e "source schema.sql"
& $mysql -u root -p --default-character-set=utf8mb4 ers -e "source data.sql"
Pop-Location
# 等价 cmd 写法（文件字节直传）
cmd /c "`"$mysql`" -u root -p --default-character-set=utf8mb4 ers < `"$repo\db\schema.sql`""
```
必须带 `--default-character-set=utf8mb4`（否则中文进库即乱码）；SQL 文件存 **UTF-8 无 BOM**；若坚持 `Get-Content .\db\schema.sql | & $mysql ...`，PowerShell 5.1 会按控制台编码转码，须先 `chcp 65001`。

### 3.3 验证
```powershell
& $mysql -u ers_app -p ers -e "SHOW TABLES;"
& $mysql -u ers_app -p ers -e "SELECT COUNT(*) FROM sys_user; SELECT COUNT(*) FROM asset;"
& $mysql -u ers_app -p ers -e "SELECT @@character_set_database, @@collation_database;"
```
期望：12 张表齐、`sys_user` 至少 1 行（种子 `admin`）、字符集 `utf8mb4` / `utf8mb4_0900_ai_ci`。已建表：`sys_user`、`asset`、`asset_record`、`transfer_request`、`credit_log`、`room`、`reservation`、`procurement`、`vote_topic`、`vote_option`、`vote_record`、`sys_config`。

> 表名以 `db/schema.sql` 为准（12 表，PRD §4.4 与 IA §6.0 S3 已同步为 `reservation`，无 `room_reservation`）。预约防重键为 `uk_reservation_slot(room_id, reserve_date, active_slot)`，`active_slot` 是生成列（仅 `BOOKED` 占位），因此文档里说的"唯一索引 `(room_id, date, time_slot)`"在实现上等价、取消后自动释放。

## 5. 前端启动
```powershell
cd D:\企业资源调度与协同治理平台\ers-web
pnpm install       # Node 24.20.0 / pnpm 12.3.4
pnpm dev           # http://localhost:5173
pnpm build         # 产物 dist/；pnpm preview 本地预览
```
开发期代理（`vite.config.ts`，`/api` → 8080）：
```ts
export default defineConfig({
  server: {
    port: 5173,
    proxy: {
      '/api': { target: 'http://localhost:8080', changeOrigin: true }   // 后端已带 /api 前缀，无需 rewrite
    }
  }
})
```
- 前端请求一律走相对路径 `/api/**`（开发期 Vite 代理、生产期 Nginx 反代），**不要**把 `http://localhost:8080` 写进 Axios `baseURL`；令牌由 Axios 请求拦截器注入 `Authorization: Bearer <token>`（存 Pinia + localStorage），401 由响应拦截器清空令牌并跳 `/login?redirect=<原路由>`（PRD §7.3）。

## 6. 生产部署
拓扑：`Nginx :80` 托管 `dist` 静态资源，并把 `/api/` 反代到 `127.0.0.1:8080`；前后端同源，无跨域。
```nginx
server {
    listen       80;
    server_name  ers.example.com;
    root         D:/ers/dist;      # Windows 路径用正斜杠
    index        index.html;
    gzip       on;
    gzip_types text/css application/javascript application/json image/svg+xml;
    location /             { try_files $uri $uri/ /index.html; }                    # SPA 深链接刷新不 404
    location /assets/      { expires 30d; add_header Cache-Control "public, immutable"; }
    location = /index.html { add_header Cache-Control "no-cache"; }                 # 入口不缓存

    location /api/ {
        proxy_pass         http://127.0.0.1:8080;    # 末尾不加斜杠，保留 /api 前缀
        proxy_set_header   Host              $host;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
```
`try_files ... /index.html` 是 SPA 必需项，缺失会让详情页刷新 404（IA §7.10 要求详情页可深链接）。

Windows 演示机（不要求 Docker）`start.bat`：
```bat
@echo off
cd /d D:\企业资源调度与协同治理平台\ers-backend
java -jar target\ers-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
pause
```
需要开机自启则用 `nssm` 注册为服务（`nssm` 与 Nginx 均需管理员权限，`D:\logs` 先建好）：
```powershell
nssm install ERS-Backend "C:\Program Files\Java\jdk-17\bin\java.exe" "-jar D:\企业资源调度与协同治理平台\ers-backend\target\ers-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod"
nssm set ERS-Backend AppStdout "D:\logs\ers-backend.out.log"
nssm set ERS-Backend AppStderr "D:\logs\ers-backend.err.log"
nssm start ERS-Backend
```

## 7. 环境变量清单
| 变量名 | 示例值 | 必填 | 说明 |
|---|---|---|---|
| `DB_URL` | `jdbc:mysql://localhost:3306/ers?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false` | 否（有默认） | 四要素：库名、编码、时区、SSL |
| `DB_USER` | `ers_app` | 否（默认 `ers_app`） | 应用账号，仅 DML |
| `DB_PASSWORD` | `<APP_DB_PASSWORD>` | **是** | 无默认值，缺失则启动失败 |
| `JWT_SECRET` | `<JWT_SECRET>`（≥32 字节） | **是** | HS256 签名密钥；泄漏等于任何人可伪造管理员令牌 |
| `JWT_TTL_HOURS` | `2` | 否（默认 2） | 令牌有效期，PRD §7.3 定为 2 小时 |
| `APP_PORT` | `8080` | 否（默认 8080） | 必须与 Nginx `proxy_pass`、Vite proxy 三处一致 |
| `REDIS_ENABLED` | `false` | 否（默认 `false`） | 关闭时须能降级：不做令牌黑名单，登录态只靠 JWT（PRD §7.1） |
| `SPRING_PROFILES_ACTIVE` | `dev` / `prod` | 否（默认 `dev`） | 演示与生产必须显式设为 `prod` |

`JWT_SECRET` 生成（48 字节随机 → Base64，约 64 字符，满足 ≥32 字节）：
```powershell
$rng   = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$bytes = New-Object byte[] 48
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```
每台机器各生成一份，**不要**跨人复用，也不要写进 `application.yml`、Git 历史或本文档。密钥更换后此前签发的令牌全部失效（表现为全员 401，见 §9 第 6 行）。
```powershell
# 当前会话有效；最后一行用 User 作用域持久化
$env:DB_PASSWORD = '<APP_DB_PASSWORD>'
$env:JWT_SECRET  = '<JWT_SECRET>'
$env:SPRING_PROFILES_ACTIVE = 'prod'
[Environment]::SetEnvironmentVariable('JWT_SECRET', '<JWT_SECRET>', 'User')   # 重开终端生效
```
`.env` 约定：本地可放 `.env`（或 `ers-backend/.env`）由启动脚本/终端读取，**`.env` 不入库**；仓库只提交 `.env.example`（键名齐全、值全为占位符）。若让 Spring Boot 直接读 `.env`，可加 `spring.config.import: optional:file:.env[.properties]`；否则由 `start.bat` 先 `set` 变量。

## 9. 常见故障排查
| # | 现象 | 可能原因 | 处理 |
|---|---|---|---|
| 1 | `Port 8080 was already in use` | 上次进程未退，或别的服务占了 8080 | 见下方查端口命令 → `Stop-Process -Id <PID>`；或改 `APP_PORT=8081` 并同步改 Vite proxy 与 Nginx |
| 2 | `Can't connect to MySQL server on 'localhost:3306'` | `MySQL80` 未启动 / 端口被改 | 管理员 `Start-Service MySQL80`；`Get-Service MySQL80` 确认 `Running`；核对 `my.ini` 的 `port` |
| 3 | `Access denied for user 'ers_app'@'localhost'` | 账号未建、密码不符、host 不是 `localhost` | 用 root 重跑 §3.1；`SELECT user,host FROM mysql.user WHERE user='ers_app';` 确认是 `localhost` 而非 `%`；核对 `DB_PASSWORD` |
| 4 | 中文变 `???` 或乱码 | 导入未指定字符集 / 排序规则不对 / PS 管道转码 | 库必须 `utf8mb4` + `utf8mb4_0900_ai_ci`；导库带 `--default-character-set=utf8mb4`；SQL 存 UTF-8 无 BOM；连接串带 `useUnicode=true&characterEncoding=utf8` |
| 5 | 时间差 8 小时 / 预约日期错位 | JVM 与 MySQL 时区不一致 | 连接串加 `serverTimezone=Asia/Shanghai`；启动加 `-Duser.timezone=Asia/Shanghai`；`SELECT @@global.time_zone, @@session.time_zone;` |
| 6 | 登录成功但后续接口全 401 | 令牌未带上 / 已过期（2h）/ `JWT_SECRET` 变更 / 时钟偏差 | Network 看请求头有无 `Authorization: Bearer ...`；重新登录；确认服务未重启换密钥；校准系统时间 |
| 7 | 前端请求 404，接口直连正常 | Vite proxy 未生效或 Nginx 未配 `/api/` | 确认请求是相对路径 `/api/**`；改 `vite.config.ts` 后要重启 `pnpm dev`；生产确认 `location /api/` 存在且 `proxy_pass` 无尾斜杠 |
| 8 | 控制台 CORS 报错 | 绕过 proxy 直连 8080，且后端未放行来源 | 开发期统一走 proxy；直连时 `dev` 放行 `http://localhost:5173`；生产用 Nginx 同源，不配 `*`（PRD §7.3） |
| 9 | `pnpm install` 卡住或 `ETIMEDOUT` | 默认源不可达 / 代理 | `pnpm config set registry https://registry.npmmirror.com`；公司代理补 `pnpm config set proxy` 与 `https-proxy`；仍失败则 `pnpm store prune` 后重装 |
| 10 | `mvnw` 依赖下载失败或极慢 | 中央仓库不可达 | `C:\Users\<用户名>\.m2\settings.xml` 加阿里云镜像（`mvnw` 与 `mvn` 共用）：`<mirror><id>aliyun</id><mirrorOf>*</mirrorOf><url>https://maven.aliyun.com/repository/public</url></mirror>`，之后 `mvnw -U` |
| 11 | Excel 导出 0 字节 / 打不开 | 异常响应被当文件下载 / 空数据无表头 / 无权限 | 看 `Content-Type` 是否为 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`；空数据也要写表头（PRD §4.7）；前端用 `responseType: 'blob'` + `<a download>` |
| 12 | 5173 被占用 | 上次 Vite 进程残留 | 同第 1 行查 PID 并结束；或 `pnpm dev --port 5174`，同步改后端放行来源 |
| 13 | 启动报 `Could not resolve placeholder 'DB_PASSWORD'` | 环境变量未设置 / profile 未加载 | 当前终端 `$env:DB_PASSWORD` 是否有值；`start.bat` 是否先 `set`；`SPRING_PROFILES_ACTIVE` 是否拼错 |
