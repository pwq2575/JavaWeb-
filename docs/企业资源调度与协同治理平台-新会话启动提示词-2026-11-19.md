## 硬性环境约束（踩过的坑，别重犯）
1. 前端只用 npm，禁止 pnpm（pnpm 12 报 ERR_PNPM_IGNORED_BUILDS / stack overflow；相关文件已删）
2. Maven：本机 PATH 里已有 3.9.9；沙箱内 `~/.m2` 不可写，一律带 `-Dmaven.repo.local=...\.tools\m2repo`
   · Bash 里用：`REPO=$(cygpath -w "$PWD/.tools/m2repo")` 再 `"-Dmaven.repo.local=$REPO"`（直接拼 `$PWD` 会变成 `D:\d\...`）
   · 离线模式会缺插件（plexus/surefire），需要联网首次解析
3. JDK 24 跑、编译目标 17；Lombok 走 `maven-compiler-plugin` 的 `annotationProcessorPaths` + `<proc>full</proc>`，别删
4. `vite build/dev` 在默认沙箱报 `spawn EPERM`：build 需单次 danger-full-access + `ESBUILD_BINARY_PATH` + `TMP/TEMP` 指到工作区（`scripts/ci.ps1` 已封装）；`vite dev` 同样需要放宽沙箱（放宽后 5173 可用，代理 `/api` → 8080 正常）
5. 本会话不再有 `pwsh` 工具，命令走 `ops_bash`（MSYS Bash）；改文件用 edit/write 工具，不要用 shell 重定向写 `docs/`（中文路径 + BOM 双坑）
6. MySQL 导入：先 `cd db` 再用相对文件名 `source schema.sql / data.sql`；中文绝对路径会 `Failed to open file`
7. 重置库顺序铁律：**先停所有后端 → `source data.sql` → 重启后端**（否则 ①旧实例的 10 分钟爽约扫描会继续扣分 ②`__DEMO__` 未 BCrypt 化，登录全 401）
8. 测试/审计脚本放 `.tmp/`（已 gitignore）；PowerShell 5.1 读 UTF-8 无 BOM 脚本会乱码，脚本保持 ASCII
9. 不要杀用户自己启动的 8080 实例、不要擅自重置用户库，除非明确同意
10. 浏览器用 `http://localhost:5173`；用 `127.0.0.1:5173` 登录会 403（`APP_CORS_ORIGIN` 默认只放行 localhost，E-17）
11. `vite dev` 运行中可能因编辑工具「原子写临时文件」触发 `EBUSY` 退出（E-15）；重启 dev 即可，构建产物不受影响
